# Code of Conduct

Such is developed as a technical open-source project maintained by Heritage Inc. Project spaces should remain useful for engineering, testing, documentation, and reproducible problem solving.

## Expected behavior

Participants are expected to:

- discuss code and technical decisions on their merits
- provide reproducible information when reporting bugs
- review contributions in good faith
- respect differences in experience, background, and technical opinion
- protect private information, credentials, security reports, and confidential material
- keep disagreement focused on the work rather than the person

## Unacceptable behavior

The following is not acceptable in project spaces:

- harassment, threats, intimidation, or discriminatory conduct
- personal attacks or sustained hostile behavior
- publishing another person's private information without permission
- knowingly submitting malicious code, credentials, secrets, or private backend material
- using security reports to threaten, extort, or publicly expose users before responsible review
- repeatedly disrupting technical discussions after being asked to stop

## Scope

This policy applies to GitHub issues, pull requests, reviews, discussions, and other project spaces operated by Heritage Inc. for Such.

## Enforcement

Maintainers may edit, hide, reject, or remove contributions and may restrict participation when behavior materially interferes with project safety or technical work.

Security-sensitive matters should follow `SECURITY.md` rather than being disclosed publicly.

For conduct concerns that should not be handled publicly, contact Heritage Inc. through https://heritage-labs.net.
